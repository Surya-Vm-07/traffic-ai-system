# Traffic AI System

A production-grade AI traffic enforcement system built with YOLOv8, FastAPI, and Docker.

## What it does
- Detects speeding vehicles from traffic camera footage
- Flags license plate violations in real time
- Exposes a REST API for integration with traffic management systems

## Tech Stack
- Python 3.11
- YOLOv8 (Ultralytics)
- FastAPI
- Docker
- pytest
